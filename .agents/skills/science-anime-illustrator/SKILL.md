# 科普手绘漫画

把用户想讲的事画成读得懂、角色连贯的多格漫画。用户可以只说一句想法、给一段文字或直接描述每格画面；不要要求固定提示词格式。默认画风是白底、粗细略不均的黑色手绘线条、圆润简化的角色、少量低饱和粉彩色块。用户给了风格参考时，提取线条、色彩、分格和文字密度等特征，不复制参考图里的角色、场景或原文。

## 主角参考

- 用户上传照片、头像或画作时，把它当作**角色身份参考**，记录 3–5 个可见特征，例如发型、眼镜、衣服、主色和配饰。每格延续这些特征。照片可转成简化漫画角色；不要臆测人物身份、年龄或现实经历。
- 用户同时上传风格图时，明确区分「主角参考」与「画风参考」。按生图工具的能力一并引用；缺图时先用用户文字描述，只有主角身份无法确定且会影响结果时才询问。
- 多页漫画先写一份简短角色设定；只有发现角色漂移或用户需要系列化时，才额外生成角色设定图，以节省时间和生图次数。

## 分镜与事实

1. 从用户的话里提取主题、情绪和重点；用户没有指定受众、格数或画幅时，按内容自行决定。科普内容要核查关键事实；医学、健康、安全或不确定的细节优先核查一手或权威资料。纯故事内容无需强行加入科普解释。
2. 可用 1080×1440 竖版、三格横向堆叠作为起点，但分镜数量与叙事顺序应服从用户内容。每格只放一个主要动作或信息点；用表情、道具、箭头和前后状态辅助表达。
3. 画面保持白底、宽留白、手绘黑边、简单背景。可选两种配色：少量柔和粉彩，或纯黑白线稿。用户的参考图和品牌色优先。
4. 每格字幕尽量不超过 16 个汉字，气泡尽量不超过两句。为保证中文字准确，可先生成无字漫画与留白气泡，再用排版工具叠加核对后的文字；不要把生图模型误写的文字当成定稿。
5. 使用可用生图工具直接生成。把上传的主角图和风格参考按各自角色传入；提示词要写清角色一致性、当前分镜内容、画幅、留白和禁止事项。无生图工具时交付逐格提示词。
6. 检查角色五官与服装是否跨格一致、分镜顺序是否通顺、箭头和标签是否符合事实、文字是否可读。发现一处关键错误就针对该处重做或后期修正。

## 交付

给出成图、每格的准确字幕，以及用于复现的提示词。若使用外部资料，附来源和核查日期。说明哪些画法是为了易懂而做的简化。用户只要样张时，先做一张，不自动扩展成整套。
